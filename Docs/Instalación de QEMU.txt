
Paso 1: Actualizar la lista de paquetes
apt update

Paso 2: Instalar QEMU y paquetes
sudo apt install qemu-kvm virt-manager libvirt-daemon-system libvirt-clients bridge-utils -y

Paso 3: iniciar y habilitar servicio de virtualización.
sudo systemctl enable --now libvirtd

paso 4: Agregar tu usuario a los grupos de virtualiación.
sudo usermod -aG libvirt,kvm $USER

Paso 5: Reiniciar el servicio de libvirt
sudo systemctl restart libvirtd

Paso 6: Reinicia la pc.
